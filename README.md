# Perseus Data:Plataforma de Predicción de Deserción Universitaria

## Descripción del Proyecto
Este proyecto analiza factores socioeconómicos y académicos que inciden en el rendimiento escolar y la tasa de retención estudiantil universitaria. A través de una herramienta interactiva en Python, exploramos patrones clave para responder a problemáticas de deserción.

## Preguntas de Investigación
1. ¿Cuál es la relación entre las horas trabajadas a la semana y el promedio académico del estudiante?
2. ¿Cómo influye el estrés financiero en la deserción universitaria durante los primeros semestres?
3. ¿Existe una diferencia en el rendimiento académico entre estudiantes de primera generación universitaria y los demás?

## Estructura del Repositorio
* `main.py`: Código fuente modular con el menú interactivo, algoritmos de búsqueda, cálculo de estadísticas y agrupación.
* `estudiantes_50.csv`: Dataset principal de análisis con 50 registros.
* `estudiantes_completos.csv`: Dataset completo del proyecto.
